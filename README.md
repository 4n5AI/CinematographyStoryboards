# Cinematography Reference

映像制作のためのシネマトグラフィー用語辞典です。

- 7つの軸
- 66の用語
- 各用語の操作、効果・印象、使い所
- 視覚効果を説明する16:9の絵コンテ
- シネマティックな動画ヒーロー
- 3カラムの用語カードと詳細ポップアップ
- 用語検索、軸フィルター、レスポンシブ対応

`index.html` をブラウザで開くと閲覧できます。GitHub Pagesではリポジトリのルートを公開対象に設定してください。
